VOD Uploader Node.js Web Application
This implementation plan outlines the architecture for converting the CLI script into a full web application with an interactive frontend, allowing you to upload files via your browser and trigger transcoding manually.

Proposed Changes
To securely upload large video files without overloading the server, we will use Presigned URLs for both upload (to send the file from the browser to S3 directly) and download (to pass the file securely to the transcoding API).

Architecture
Backend: Express.js server providing API routes.
Frontend: A rich, premium, modern HTML/CSS/JS single page application using glassmorphism aesthetics.
Backend Routes
GET /api/presign-upload: Creates an S3 presigned URL for uploading (PUT), giving the browser permission to upload directly to S3.
POST /api/transcode: Receives the filename, generates a 2-hour presigned URL for download (GET), and triggers the transcoding webhook API.
